# Mesa de Partes Digital

Prototipo en Python del curso Fundamentos de Programación (UPN).
Permite registrar expedientes y buscarlos por número. Los datos se guardan en el archivo `expedientes.txt`.

## Estructura
- `main.py`: menú principal, registro y búsqueda
- `validaciones.py`: validación de los datos ingresados
- `archivos.py`: generar, guardar, cargar y buscar expedientes

## Ejecutar
python main.py
